What exactly does PeerMate do?

It follows approved course groups, understands important updates and shared materials, then answers registered students privately with clear source details.

Does PeerMate send messages into my class group?

No. PeerMate is designed as a quiet reader. It never posts in the group; its useful work happens in a private student-initiated conversation.

Can it understand voice notes and timetable photos?

Yes. The prototype can transcribe voice notes, read timetable images and extract useful dates, times, venues and course details.

Can PeerMate find files shared weeks ago?

Yes—if the file arrived after PeerMate joined the approved group. It stores and tags course resources so students can request them later.

Is PeerMate ready for real student groups?

Not yet. The current prototype is tested with staged groups and synthetic messages while production consent, access control, retention and deletion safeguards are completed.
